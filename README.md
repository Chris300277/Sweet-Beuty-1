# Sweet Beauty

E-commerce de productos de belleza y maquillaje orientado al mercado colombiano.

## Objetivo

Desarrollar una plataforma web funcional que permita a los usuarios consultar, buscar, seleccionar y comprar productos de belleza.

## Estado

Proyecto en desarrollo.

## Documentación

La documentación del proyecto se encuentra en la carpeta `docs`.

## Estructura

- `src/` — código fuente
- `public/` — recursos públicos
- `assets/` — imágenes y recursos visuales
- `docs/` — documentación del proyecto
- `tests/` — pruebas
